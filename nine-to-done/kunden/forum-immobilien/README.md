# Forum Immobilien: Website

Auftrag: Webseite für das Maklerbüro **Forum Immobilien** (Hans-Eckhard Röher) in Hagenbach. Bestehende Seite: https://www.forum-roeher.de, umgesetzt von **Nine to Done**.

Gebaut wird mit dem Skill `website-bauen` (liegt unter `.claude/skills/website-bauen/` im Repo).
Den aktuellen Stand zeigt [WEBSITE-STATUS.md](WEBSITE-STATUS.md). In einem neuen Chat geht es mit `/website-bauen weiter` weiter.

## Ordner

| Ordner | Inhalt |
|---|---|
| `briefing/` | Auftrag, Anforderungen, Absprachen mit dem Kunden |
| `inhalte/texte/` | Texte vom Kunden (Über uns, Leistungen, Impressum, Datenschutz) |
| `inhalte/bilder/` | Logo, Fotos vom Makler/Team, Objektfotos |
| `referenzen/` | Screenshots und Notizen zu Vorbildern (Phase 2) |
| `recherche/` | Keyword- und GEO-Karte, Wettbewerber (Phase 2) |
| `design/` | Entwürfe, Farben, Schriften |
| `website/` | Der eigentliche Code der Webseite |
| `archiv/` | Alte Entwürfe, nie löschen |
