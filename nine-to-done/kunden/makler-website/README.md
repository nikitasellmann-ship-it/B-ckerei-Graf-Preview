# Makler-Website

Auftrag: Webseite für einen Immobilienmakler, umgesetzt von **Nine to Done**.

## Ordner

| Ordner | Inhalt |
|---|---|
| `briefing/` | Auftrag, Anforderungen, Absprachen mit dem Kunden |
| `inhalte/texte/` | Texte vom Kunden (Über uns, Leistungen, Impressum, Datenschutz) |
| `inhalte/bilder/` | Logo, Fotos vom Makler/Team, Objektfotos |
| `design/` | Entwürfe, Farben, Schriften |
| `website/` | Der eigentliche Code der Webseite |

## Noch vom Kunden zu klären

- [ ] Name des Maklerbüros, Adresse, Kontaktdaten
- [ ] Logo und Farbwünsche
- [ ] Gewünschte Seiten (z. B. Start, Immobilien, Leistungen, Über uns, Kontakt)
- [ ] Sollen Immobilien-Angebote auf der Seite gelistet werden? (manuell oder per Schnittstelle, z. B. ImmoScout24 / OpenImmo)
- [ ] Kontaktformular / Wertermittlungs-Anfrage gewünscht?
- [ ] Domain und Hosting vorhanden?
- [ ] Impressum- und Datenschutz-Angaben
